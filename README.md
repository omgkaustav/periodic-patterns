# Periodic Patterns

A browser lab for pattern-forming systems on a **square** or **hexagon** tile with periodic attachment rules (translate, flips, 180° rotation, mirrors). The field wraps at the edges, so the wallpaper is seamless.

**Live:** <https://omgkaustav.github.io/periodic-patterns/>

## Generators

- Gray–Scott reaction–diffusion
- Lattice Kuramoto
- Young activator–inhibitor
- Periodic flow field (stream function + line-integral convolution)

## Run locally

```
python3 -m http.server 8080
```

Then open <http://localhost:8080>.
